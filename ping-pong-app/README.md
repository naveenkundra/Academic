# Ping Pong

A simple browser-based Pong game built with HTML5 Canvas and vanilla JavaScript.

## Play

Open `index.html` in any modern web browser.

## Controls

- **Player 1 (left paddle):** `W` / `S`
- **Player 2 (right paddle, 2-player mode):** `Arrow Up` / `Arrow Down`
- Switch between **1 Player (vs CPU)** and **2 Players** using the radio buttons
- Use **Start**, **Pause**, and **Reset** to control the game

## Rules

First to 11 points wins. The ball bounces off the top/bottom walls and paddles, with the bounce angle depending on where it hits the paddle.
